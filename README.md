# 🏫 Orbit International School Website

A modern, fully responsive, and feature-rich frontend web application built for **Orbit International School**. This project showcases the school's history, administration, faculty members, academic programs, and an interactive photo gallery.

## ✨ Key Features
* **Modern UI & Dark/Light Mode:** Seamless theme switching between light and dark modes with smooth transition overlays.
* **Splash Screen / Preloader:** An engaging animated intro screen that greets visitors upon loading.
* **Interactive Photo Gallery:** Categorized photo grid with a custom full-screen lightbox slider for viewing campus, classrooms, sports, and events.
* **Faculty & Administration Profiles:** Dedicated sections introducing the Founder, Principal, and experienced teachers.
* **Academic Information:** Comprehensive details on curriculum, shift timings, air-conditioned smart classrooms, and extra coaching facilities.
* **Google Maps Integration:** Embedded location map for easy campus navigation.
* **Fully Responsive:** Optimized for all devices, including mobile phones, tablets, and desktop computers.
